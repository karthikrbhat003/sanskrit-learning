# Sanskrit Pronunciation & Script (Devanāgarī)

Sanskrit is written in the **Devanāgarī** (देवनागरी) script. It is a highly phonetic language, meaning words are pronounced exactly as they are written. 

---

## 🅰️ The Alphabet (Akṣaramālā - अक्षरमाला)

Sanskrit has 46 standard letters (13 Vowels and 33 Consonants).

### 1. Vowels (Svarāḥ - स्वराः)
Vowels can be short (hrasva) or long (dīrgha). Long vowels are held twice as long as short ones.

| Devanagari | IAST | Type | Pronunciation Guide |
| :--- | :--- | :--- | :--- |
| **अ** | a | Short | like **u** in *but* |
| **आ** | ā | Long | like **a** in *father* |
| **इ** | i | Short | like **i** in *pin* |
| **ई** | ī | Long | like **ee** in *meet* |
| **उ** | u | Short | like **u** in *put* |
| **ऊ** | ū | Long | like **oo** in *boot* |
| **ऋ** | ṛ | Short | vocalic **r** (like **ri** in *rhythm* or **er** in *her*) |
| **ॠ** | ṝ | Long | prolonged vocalic **r** (rarely used) |
| **ऌ** | ḷ | Short | vocalic **l** (like **li** in *lily*) |
| **ए** | e | Long | like **ay** in *say* (always long in Sanskrit) |
| **ऐ** | ai | Long | like **ai** in *aisle* or **y** in *my* |
| **ओ** | o | Long | like **o** in *go* (always long in Sanskrit) |
| **औ** | au | Long | like **ow** in *cow* |

### 2. Yogavāhas (Modifiers)
*   **Anusvāra (ं / ṃ)**: Nasalizes the preceding vowel (e.g., अं - am).
*   **Visarga (ः / ḥ)**: A voiceless breath echo. It repeats the preceding vowel with a soft breath (e.g., अः is pronounced *aha*, इः is *ihi*, उः is *uhu*).

### 3. Consonants (Vyañjanāni - व्यञ्जनानि)
Consonants are organized scientifically by their point of articulation in the mouth, moving from the back (throat) to the front (lips).

#### Group 1: Kaṇṭhya (Velar - Throat)
| Devanagari | IAST | Sound Type | Pronunciation Guide |
| :--- | :--- | :--- | :--- |
| **क** | ka | Unaspirated | **k** in *kite* |
| **ख** | kha | Aspirated | **k-h** in *blockhead* (more air) |
| **ग** | ga | Unaspirated | **g** in *go* |
| **घ** | gha | Aspirated | **g-h** in *doghouse* |
| **ङ** | ṅa | Nasal | **ng** in *sing* |

#### Group 2: Tālavya (Palatal - Roof of mouth)
| Devanagari | IAST | Sound Type | Pronunciation Guide |
| :--- | :--- | :--- | :--- |
| **च** | ca | Unaspirated | **ch** in *church* |
| **छ** | cha | Aspirated | **ch-h** in *match-head* (more air) |
| **ज** | ja | Unaspirated | **j** in *joy* |
| **झ** | jha | Aspirated | **j-h** in *hedge-hog* |
| **ञ** | ña | Nasal | **ny** in *canyon* |

#### Group 3: Mūrdhanya (Retroflex - Tongue curled back against the roof)
| Devanagari | IAST | Sound Type | Pronunciation Guide |
| :--- | :--- | :--- | :--- |
| **ट** | ṭa | Unaspirated | **t** with tongue curled back |
| **ठ** | ṭha | Aspirated | **t-h** with tongue curled back |
| **ड** | ḍa | Unaspirated | **d** with tongue curled back |
| **ढ** | ḍha | Aspirated | **d-h** with tongue curled back |
| **ण** | ṇa | Nasal | **n** with tongue curled back |

#### Group 4: Dantya (Dental - Tongue touching upper teeth)
| Devanagari | IAST | Sound Type | Pronunciation Guide |
| :--- | :--- | :--- | :--- |
| **त** | ta | Unaspirated | **t** in Spanish *tres* or French *tu* |
| **थ** | tha | Aspirated | **t-h** in *hot-house* (dental) |
| **द** | da | Unaspirated | **d** in Spanish *dos* |
| **ध** | dha | Aspirated | **d-h** in *adhere* (dental) |
| **न** | na | Nasal | **n** in *name* |

#### Group 5: Oṣṭhya (Labial - Lips)
| Devanagari | IAST | Sound Type | Pronunciation Guide |
| :--- | :--- | :--- | :--- |
| **प** | pa | Unaspirated | **p** in *spin* (unaspirated) |
| **फ** | pha | Aspirated | **p-h** in *uphill* (not like 'f') |
| **ब** | ba | Unaspirated | **b** in *boy* |
| **भ** | bha | Aspirated | **b-h** in *clubhouse* |
| **म** | ma | Nasal | **m** in *mother* |

#### Semivowels (Antastha - अन्तःस्थ)
*   **य (ya)**: like **y** in *yes* (Palatal)
*   **र (ra)**: lightly rolled **r** (Retroflex)
*   **ल (la)**: dental **l** in *love* (Dental)
*   **व (va)**: soft labio-dental sound between **v** and **w** (Labial/Dental)

#### Sibilants & Aspirate (Ūṣmāṇaḥ - ऊष्माणः)
*   **श (śa)**: soft sibilant like **sh** in *sheep* (Palatal)
*   **ष (ṣa)**: retroflex sibilant like **sh** in *bush* with tongue curled back
*   **स (sa)**: dental sibilant like **s** in *sit*
*   **ह (ha)**: voiced aspirate like **h** in *home*

## ✍️ Halanta & Conjuncts
*   **Virāma / Halanta (्)**: Standard consonant letters have an inherent 'a' sound (e.g., क् + अ = क). To represent a pure consonant without a vowel, we add a diagonal stroke underneath (e.g., **क्** - *k*).
*   **Samyuktākṣara (Conjunct Consonants)**: When two or more consonants appear together without an intervening vowel, they merge into a conjunct glyph:
    *   त् + य = **त्य** (tya)
    *   ष् + ण = **ष्ण** (ṣṇa)
    *   क् + ष = **क्ष** (kṣa)
    *   ज् + ञ = **ज्ञ** (jña / gnya)
